## ⚠️ 常见问题

### Q1: 测试失败怎么办？

**查看错误信息**：
- 测试会显示具体的错误消息
- 查看logger输出的异常详情

**常见原因**：
1. **导入错误** - 确保在项目根目录运行
2. **依赖缺失** - 检查 event_loop.py 和 async_wrapper.py 是否存在
3. **权限问题** - 确保有文件读写权限

### Q2: Windows上应该看到什么？

**应该看到**：
- 事件循环类型：`ProactorEventLoop` (IOCP)
- 平台信息：`win32`

**如果看到** `SelectorEventLoop`：
- 可能是Python版本问题（需要3.8+）
- 或者在非Windows系统上运行

### Q3: 性能测试失败？

**性能测试标准**：
- 添加100个任务：< 1秒
- 1秒内执行次数：> 1000次

**如果失败**：
- 可能是CPU性能限制
- 或者系统资源不足
- 不影响基本功能，可以继续

### Q4: 如何调试单个测试？

**方法1**：修改 `test_iocp_basic.py`
```python
if __name__ == "__main__":
    # 只运行特定测试
    test_scheduler_creation()
```

**方法2**：使用快速测试
```bash
python quick_iocp_test.py
```
