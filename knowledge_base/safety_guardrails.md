# 安全拦截规则库（Guardrails）

> 定义敏感话题的分级、检测词库和拦截策略。
> 由 `SafetyGuard` 类读取并执行。

---

## 一、敏感话题分级

### 🔴 高危（Hard Block）— 必须拦截，直接返回安全引导

- **自残/自杀**：用户表达自杀意图、自残计划、厌世情绪
- **暴力/犯罪**：用户询问如何犯罪、伤害他人、制造武器
- **儿童色情**：任何涉及未成年人的色情内容
- **恐怖主义**：涉及恐怖组织、爆炸物制作等

**拦截策略**：
- 不回答任何问题
- 提供心理援助热线或报警电话
- 温和但坚定地拒绝继续讨论
- 记录到日志（不存储到记忆库）

### 🟡 中危（Soft Block）— 建议拦截，转移话题

- **涉政敏感**：涉及政治立场、敏感事件、意识形态争论
- **成人色情**：一般色情内容
- **赌博/诈骗**：诱导赌博、诈骗技巧
- **毒品/药物滥用**：毒品获取、药物滥用方法

**拦截策略**：
- 表示不方便讨论
- 自然转移话题
- 不深入任何立场

### 🟢 低危（Monitor）— 仅记录，正常回答

- **轻微负面情绪**："好烦"、"不想活了"（口头禅级别，非真实意图）
- **粗口/脏话**：不文明用语
- **争议话题**：一般性争议话题

**拦截策略**：
- 正常回答，但降低记忆权重（×0.3）
- 不主动强化负面情绪

## 四、安全规则代码映射

| 话题类别 | 关键词命中 | 语义判断 | 处理方式 |
|----------|-----------|---------|---------|
| 自杀/自残 | 是 | 无需 | 立即拦截 + 提供热线 |
| 暴力/犯罪 | 是 | 无需 | 立即拦截 + 提供报警 |
| 涉政/色情 | 否 | 是 | 转移话题 |
| 轻微情绪 | 是 | 否 | 正常回答 + 降权 |

---

## 五、实现说明

1. **关键词匹配**：`SafetyGuard._check_keywords()` 使用 trie 树或简单 in 判断
2. **语义判断**：`SafetyGuard._check_llm()` 使用零样本 LLM 判断（备用）
3. **拦截执行**：`SafetyGuard.intercept()` 返回拦截结果，阻断 LLM 调用
4. **日志记录**：高危事件记录到独立日志 `logs/safety.log`，不进入记忆库
